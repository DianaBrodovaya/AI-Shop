# Заметки о релизе

Обновление стоит поставить, если каталог должен спокойно переживать сбои поставщика, а не «молча ломаться» на странном ответе. В этой версии клиент API жёстче следует контракту: битый JSON, пустой или неполный ответ и отсутствие обязательных полей товара больше не превращаются в необработанные исключения. Вместо этого вы получаете предсказуемые ошибки домена — и можете опираться на фолбэк и понятные состояния интерфейса (`loading` / `retrying` / `fallback` / `failed`), а не на пустой экран или падение рендера.

Заметно меняется ощущение устойчивости: повторные попытки и кеш работают в связке с валидным ответом, а не с «почти данными», у которых нет цены или идентификатора. Для команды разработки ценность ещё и в регрессионных тестах на обработку ошибок каталога — поведение зафиксировано, и следующий рефакторинг не откатит защиту молча.

Если коротко: обновляйтесь ради спокойнее работающего магазина при нестабильном API и ради того, чтобы невалидные ответы поставщика отсекались на границе, а пользователь видел контролируемый сценарий вместо сюрпризов в консоли.
