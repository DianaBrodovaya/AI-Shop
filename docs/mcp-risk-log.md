# Журнал рисков MCP

## Подключённые серверы

### Playwright MCP

- Пакет: `@playwright/mcp@latest`
- Транспорт: stdio через `npx`
- Назначение: автоматический запуск e2e-тестов агентом из редактора
- Политика подтверждений: только чтение — автоматически, меняющие состояние — подтверждение, `browser_evaluate`/`browser_run_code` — подтверждение обязательно
- Дата подключения: 2026-04-13

## Риски

| # | Риск | Вероятность | Последствия | Мера |
|---|---|---|---|---|
| R1 | Агент запускает `browser_run_code` с произвольным JS | низкая | критичное (любое действие в браузере) | Подтверждение обязательно. Не отключать в Auto-Run |
| R2 | Агент кликает кнопки отправки на реальных страницах | средняя | серьёзное (отправка данных) | Сквозные тесты только против локального сервера разработки. Confirm на `browser_click`, `browser_type` |
| R3 | Скачивание браузерного ядра Chromium при первом запуске зависает (300+ МБ) | средняя | мелкое (выглядит как зависание) | Документация явно предупреждает: первый вызов = `browser_install` + загрузка ~3 минуты |
| R4 | Сквозные тесты нестабильны (состояния гонки) | средняя | мелкое (ложные срабатывания) | Использовать `browser_wait_for` вместо фиксированных таймаутов |
| R5 | MCP передаёт скриншоты с приватными данными в контекст модели | низкая | мелкое (скриншоты только локального dev) | Тестируем только мок-данные, не прод |

## Что не подключено и почему

- **GitHub MCP** не используется: Cursor не поддерживает OAuth для GitHub MCP, требует PAT, что выводит секреты в проектный файл. Для работы с GitHub из агента — `gh` CLI через bash-инструмент.
