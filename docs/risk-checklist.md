## Безопасность

- [x] В коде нет жёстко заданных ключей, токенов, паролей. — подтверждено: ключ только через `getApiKey()` → `import.meta.env.VITE_API_KEY`.
- [x] API-ключи читаются из переменных окружения (`VITE_API_KEY` в `.env`, не в репозитории). — `.env` в `.gitignore`, в репозитории только `.env.example`.
- [ ] Нет зависимостей с известными уязвимостями (`npm audit`). — **не пройден:** `npm audit` сообщает 19 moderate (цепочка `minimatch` через `eslint` / `@eslint-react/*`). Исправление через `npm audit fix --force` откатывает ESLint до 9.x (breaking). План: не форсить даунгрейд в этом релизе; в следующем — обновить `@eslint-react/eslint-plugin` / `eslint`, когда апстрим закроет advisory, либо точечно поднять `minimatch` без смены мажора ESLint.
- [x] MCP-серверы имеют минимально необходимые разрешения (approve flow настроен). — подтверждено: в `docs/mcp-inventory.md` / `docs/mcp-risk-log.md` / `AGENTS.md` чтение авто, state-changing и `browser_evaluate`/`browser_run_code` — только с подтверждением; подключён только Playwright MCP.
